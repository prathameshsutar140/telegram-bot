# Telegram Productivity Manager Bot

A lightweight, interactive Telegram bot designed to serve as a personal productivity assistant and task tracker—no external AI APIs required!

## Features
* 📋 **Task Management:** Automatically adds incoming text messages as pending tasks.
* 🤖 **Smart Text Handling:** Categorizes messages and provides friendly/humorous responses for code requests and greetings.
* ⚡ **Zero External AI Dependencies:** Runs purely using `python-telegram-bot` event handling and rule-based logic.
* 📱 **Telegram Menu Integration:** Pre-configured command menu (`/tasks`, `/done`, `/today`, `/help`).

## Tech Stack
* **Language:** Python 3.x
* **Library:** `python-telegram-bot`
